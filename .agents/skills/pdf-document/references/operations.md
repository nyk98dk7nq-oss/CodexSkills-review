# PDF 操作定義

`edit` は UTF-8 JSON の配列、または `operations` 配列を持つオブジェクトを受け取る。操作を上から順に適用する。ページ番号と挿入位置は 1 始まりとする。既存出力を上書きしない。

主出力またはその既存祖先フォルダがシンボリックリンクの場合は処理を拒否する。リンク切れの出力シンボリックリンクも既存出力として扱う。編集済み PDF は同一フォルダの一時ファイルへ完成させてから、未作成の主出力へ確定する。

## 回転

```json
{"op": "rotate", "pages": [1, 3], "degrees": 90}
```

- `pages` は番号配列または `"all"` とする。
- `degrees` は 90 の倍数とする。

## 削除

```json
{"op": "delete", "pages": [2]}
```

全ページの削除は拒否する。後続操作のページ番号は削除後の順序を基準とする。

## 並べ替え

```json
{"op": "reorder", "pages": [3, 1, 2]}
```

現在の全ページを重複なく 1 回ずつ指定する。指定漏れによる暗黙の削除は行わない。

## 結合

```json
{
  "op": "merge",
  "file": "appendix.pdf",
  "pages": "all",
  "position": "end"
}
```

- 相対 `file` は操作定義 JSON のフォルダを基準に解決する。
- `pages` は結合元 PDF のページ番号配列または `"all"` とする。
- `position` は `"end"`、または現在の PDF に挿入する 1 始まりの位置とする。

## メタデータ

```json
{"op": "metadata", "values": {"Title": "更新版設計書", "Author": "開発部"}}
```

キー先頭の `/` は省略できる。値は文字列として保存する。

## 複数操作の例

```json
{
  "operations": [
    {"op": "rotate", "pages": [1], "degrees": 90},
    {"op": "delete", "pages": [4]},
    {"op": "metadata", "values": {"Title": "レビュー用"}}
  ]
}
```
