# PPTX操作仕様

入力と出力には異なる未作成パスを指定する。出力パス自体または既存祖先がシンボリックリンクなら拒否し、壊れたリンクも既存出力として扱う。JSONは操作の配列、または `operations` 配列を持つオブジェクトとする。操作は記載順に適用する。

```json
{
  "operations": [
    {"op": "replace_text", "old": "旧名称", "new": "新名称", "count": 1},
    {"op": "set_shape_text", "slide": 2, "shape_name": "テキスト ボックス 3", "text": "更新した説明"}
  ]
}
```

- `replace_text`: 全スライドのテキスト図形、表セル、ノートを検索する。`count` は省略可能で、指定時はプレゼンテーション全体での最大置換回数とする。複数runにまたがる文字列も置換するが、該当段落の文字装飾は先頭runへまとめられるため出力を目視確認する。
- `set_shape_text`: `slide` は1始まりのスライド番号、`shape_name` はMarkdownに出力された図形名を指定する。スライド番号と図形名を主キーとする。同一スライド内で図形名が重複する場合は `shape_id` も指定して絞り込む。`shape_name` を指定せず `shape_id` だけを使う旧JSONも後方互換用に受け付ける。グループ内図形も指定できる。テキストフレームを持たない図形は拒否する。
- 対象が存在しない操作、範囲外の索引、上記以外の操作は拒否する。
- 既存の出力ファイルは上書きせず、処理開始前に拒否する。

Markdown変換時に `--images-dir` を指定すると、通常画像と画像が挿入済みの画像プレースホルダーを `{元ファイル名}-slide-{スライド番号}-shape-{図形ID}.{拡張子}` へ抽出し、Markdown出力位置からの相対リンクを記録する。画像ディレクトリ、予定画像、それらの既存祖先にあるシンボリックリンクは拒否する。抽出予定パスはすべて先に確認し、1件でも既存、壊れたリンク、または重複パスがあれば画像とMarkdownの両方を書き込まない。

背景はスライド、レイアウト、マスターの順に最初の明示 `p:bg` を使い、下位の単色背景等が上位の画像背景を上書きする場合の誤検出を避ける。`p:bg/p:bgPr/a:blipFill/a:blip` が `r:embed` または `r:link` の画像relationshipを持つ場合だけ、スライド番号、由来パート、relationship IDと参照先、「背景画像は抽出対象外・要確認」をMarkdownに記録する。単色、グラデーション等にはマーカーを出さない。背景画像自体の抽出は初版の対象外とする。
