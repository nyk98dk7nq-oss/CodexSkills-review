# 旧 Office 変換仕様

## 対応表

| 入力 | 出力 | COM ProgID | 保存形式番号 |
| --- | --- | --- | ---: |
| `.xls` | `.xlsx` | `Excel.Application` | 51 (`xlOpenXMLWorkbook`) |
| `.doc` | `.docx` | `Word.Application` | 16 (`wdFormatDocumentDefault`) |
| `.ppt` | `.pptx` | `PowerPoint.Application` | 24 (`ppSaveAsOpenXMLPresentation`) |

マクロを含む旧形式でもマクロなしの Open XML 形式へ変換する。マクロ保持形式への変換はこの Skill の対象外とし、必要な場合は利用者へ確認する。

## COM の扱い

1. `pythoncom.CoInitialize()` を呼ぶ。
2. `DispatchEx` で形式に対応する Office アプリを専用プロセスとして起動する。
3. 警告表示を抑止し、入力を読み取り専用で開く。
4. 対応表の保存形式番号で未作成の出力先へ保存する。
5. `finally` で文書を閉じ、アプリの `Quit()` を呼び、`CoUninitialize()` を呼ぶ。
6. 失敗時に途中出力があれば削除する。

最終出力またはその既存祖先フォルダがシンボリックリンクの場合は、リンク切れを含めて変換前に拒否する。Office には同一出力フォルダ内の一時ファイルを渡し、文書とアプリを閉じて COM を解放した後、未作成の最終出力へ確定する。

## バッチ変換

- 入力フォルダを再帰走査する。
- 入力フォルダからの相対パスを出力フォルダにも保持する。
- 対応する拡張子だけを対象にする。
- 出力競合を全件確認してから変換を始める。
- 途中の1件が失敗した場合は、そのバッチ実行で既に作成した出力と失敗途中の出力を削除し、入力原本と実行前から存在した出力は変更しない。
- 変換元と変換後の対応はオーケストレータが manifest に記録する。

## 停止条件

- Windows 以外である。
- Python 3.12 未満である。
- `pywin32` を import できない。
- Microsoft Office の対象アプリがインストールされていない、または COM 登録がない。
- 入出力の拡張子対応が不正である。
- 出力先が既に存在する。
