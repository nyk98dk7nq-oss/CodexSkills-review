# チェックリスト

レビューに使用するチェックリストを置くフォルダです。

- 原則として XLSX 形式のチェック項目表を置きます。
- 複数のチェックリストを配置できます。
- 参考資料を指定する場合は、`input/references/...` の相対パスをチェックリストへ記載します。
- レビュー対象や参考資料そのものは、このフォルダへ置きません。
- レビュー時は原本を `output/reviews/yyyyMMddhhmm/` へコピーし、コピーの既存列の右側へ、対象ファイル1件につき `レビュー対象ファイル名`、`レビュー結果`、`レビューコメント` の3列を追加します。
- レビュー結果には `適合`、`不適合`、`対象外`、`要確認` の4種類を使用します。
- 同じ実行時刻フォルダへ、不適合項目と改善案を中心とする `summary.md` を作成します。

実際のチェックリストは通常の Git 管理対象になりません。
