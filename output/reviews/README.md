# レビュー結果

レビュー実行後の結果記入済みチェックリストを保存するフォルダです。

レビュー実行時のローカル時刻を `yyyyMMddhhmm` 形式にしたフォルダを作成し、その中へ `input/checklists/` のチェックリストを元のファイル名でコピーします。

```text
output/reviews/
└─ 202608171930/
   └─ <チェックリストの元ファイル名>.xlsx
```

コピーしたチェックリストの既存列の右側へ、レビュー対象ファイル1件につき次の3列を追加します。

1. `レビュー対象ファイル名`
2. `レビュー結果`
3. `レビューコメント`

チェック項目の各行について、対象ファイル数分の結果を記入します。レビュー結果は `適合`、`不適合`、`対象外`、`要確認` の4種類です。レビューコメントには、AI が判定した根拠と確認可能な該当箇所を記載します。

実行前にレビュー用の入力ファイルを置く必要はありません。生成された結果は通常の Git 管理対象になりません。
