# Skills

Skill Creator が作成・検証した Skill を格納するフォルダです。利用者のチェックリスト、参考資料、レビュー対象は置かないでください。

作成する Skill は次の8つです。

- `xlsx-document`
- `docx-document`
- `pptx-document`
- `pdf-document`
- `image-document`
- `convert-legacy-office`
- `review-markdown-documents`
- `review-documents-orchestrator`

各 Skill は `SKILL.md`、`agents/openai.yaml`、必要な `scripts/`、`references/`、`assets/`、`tests/` だけで構成します。個別の Skill フォルダには追加の README を作成しません。
